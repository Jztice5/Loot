## 归档规则

- 过程日志进入事件发生日期对应的 `yyyy-Qn/` 目录。
- 季度总览命名为 `开发过程总览-yyyy-Qn.md`。
- 单篇日志继续使用 `yyyy-MM-dd-主题.md`，兼顾日期排序和季度查询。
- [TEMPLATE.md](TEMPLATE.md) 保持固定路径，供所有季度复用。

## 时间语义

- development log 只保存过去的判断、改动和证据，不维护当前任务队列。
- 日志结束时的未决判断统一使用“当时遗留事项（历史快照）”，不得使用容易被当成当前
  指令的“下一步”“后续”或“下一环节”标题。
- 仍需执行的事项必须登记到当前季度需求管理；日志只保留需求链接或当时判断。
